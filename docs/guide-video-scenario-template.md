# 사용 가이드 애니메이션 시나리오 양식

케이스 A(30~50대 · 자녀와의 고민), 케이스 B(연인·배우자와의 고민) 두 벌을 채워주세요.
장면 흐름: ① 가상 카카오톡(문제 상황) → ② 대시보드 → ③ 인물 등록 → ④ 대화 업로드 → ⑤ 체크인
→ ⑥ AI 분석 → ⑦ 리포트 → ⑧ AI 상담 → ⑨ 마무리 카카오톡(달라진 대화)

`( )` 안은 예시입니다. ②·④·⑥은 등록 정보로 자동 구성되므로 따로 쓸 게 없어요.

## 케이스 A — 30~50대 · 자녀와의 관계

### 공통 인물 정보
- 상대 이름: (예: 김민준)
- 관계 유형: 가족 (고정)
- 카톡방 제목: (예: 아들 / 민준 — 이모지 포함 가능)
- 아바타 글자 1자: (예: 민)

### ① 가상 카카오톡 — 문제 상황 (첫 장면)
> 형식: [나] 또는 [상대] + 말풍선 내용. 2~4개 메시지 권장. 냉랭하거나 서먹한 분위기.
- 날짜: (예: 8월 12일 화요일)
- [나] (예: 아들, 주말에 집에 안 내려오니? / 오후 8:10)
- [상대] (예: 바빠요. 다음에요. / 오후 10:42)
- [나] (예: …그래, 알겠다. / 오후 10:45)
- 마지막 연출: (예: 읽음 표시만 남고 답장 없음 / 또는 없음)

### ⑤ 체크인 (슬라이더 1~7, 낮을수록 힘듦)
- "요즘 이 사람과의 관계, 어떻게 느껴지세요?": (예: 2)
- "최근 이 사람과 대화할 때 얼마나 편안함을 느끼시나요?": (예: 3)

### ⑦ 리포트
- 종합 온도 점수(0~100): (예: 48)
- 변화: (예: ▼ 5)
- PRQC 6요소 점수 — 만족/헌신/친밀/신뢰/열정/사랑 순: (예: 40/62/35/70/30/68)
- 근거 카드 1 — 태그 + 한두 문장: (예: 친밀감 · "최근 한 달간 자녀가 먼저 연락한 횟수가 2회로 줄었어요.")
- 근거 카드 2 — 태그 + 한두 문장: (예: 신뢰 · "짧은 답장이 늘었지만, 부모님 안부를 묻는 말은 꾸준히 있어요.")

### ⑧ AI 상담
- 내가 보내는 질문: (예: 아이가 점점 멀어지는 것 같아. 대화 분석 결과는 어때?)
- AI 답변 (강조할 단어·수치가 있으면 «강조» 표시): (예: 민준님과의 관계가 예전 같지 않아 속상하셨겠어요. 최근 대화를 보면 답장은 짧아졌지만 «생일», «건강 챙기세요» 같은 표현은 꾸준히 있었어요. 먼저 «주말 식사» 같은 부담 없는 제안을 해보시는 건 어떨까요?)
- 추천 질문 버튼 2개: (예: 요즘 아이가 무슨 이야기를 제일 많이 해? / 어떻게 말을 걸면 좋을까?)

### ⑨ 마무리 카카오톡 — 달라진 대화
- 날짜: (예: 8월 20일 수요일)
- [나] (예: 민준아, 이번 주말에 네가 좋아하는 갈비 해놓을게. 얼굴만 보고 가 / 오후 7:02)
- [상대 답장] (예: ㅎㅎ 알겠어요 토요일에 갈게요. 오랜만에 엄마 밥 먹고 싶었어요 / 오후 7:15)
- 마지막 리액션 이모지: (예: ❤️)
